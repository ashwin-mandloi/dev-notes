Welcome to Dev Notes.

This is my personal technical learning space as a Software Developer.

I use these notes to capture the concepts, questions, and practical observations I discover while learning. Each topic contains a short concept overview, followed by the questions that came from my curiosity and the answers I found.

The purpose is simple: when I return to a topic in the future—whether for a project, design discussion, or interview—I should not need to start learning from the beginning. I can quickly see what I already understood, what questions I explored, and where I stopped.

These notes are not intended to be a complete textbook or official documentation. They reflect my understanding at the time of writing and will evolve as I gain more experience.
